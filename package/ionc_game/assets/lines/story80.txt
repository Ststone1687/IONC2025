天還沒亮，走廊外的光線只是淡淡一層灰。
宿舍內一片安靜，只有空調低鳴與幾聲輕微的翻身聲響。
我睜開眼，沒有睏意，像是身體比我更早意識到今天的份量。
（第五天了啊。）
走下床、洗漱、換衣。這些動作在過去幾天已變得機械而熟練，卻在今晨顯得格外安靜。
我提早出門，走到資電館外。清晨的空氣清涼中帶著濕氣，遠方的天空還未完全亮起，像極了未初始化的程式碼——含混、未定，卻充滿可能。
腳步聲從背後靠近。
朋友：「欸，果然在這邊。」
我轉頭，他背著筆電包，邊走邊哈著氣，嘴角一如往常地彎著。
朋友：「怎樣，昨晚是不是還在想題目想太多？我夢到我們一起寫 code，結果夢裡我打了一千行都沒 compile 過。」

朋友：「喂喂，一早就這麼毒，這是打算氣死我讓我無法參賽嗎？」
他邊說邊走到我旁邊，像是自然而然就該在這裡。
我們並肩站著，看著天色一點點變亮。
朋友：「其實我昨天睡前還有點小緊張耶。結果現在一看到你，就沒事了。」
我偏過頭看他。
主角：「我又沒幫你 debug，你就不緊張了？」
朋友：「你這傢伙就是我最強的 debugger 好嗎。」
他笑了一聲，又像是認真起來。
朋友：「這幾天……我真的滿慶幸，跟你同一組。」
主角：「為什麼？」
他沒有馬上回答，只是看向遠方，像是在整理思緒。
朋友：「因為我一直以為，程式比賽就只是自己努力、自己衝，結果和你一起打團體賽之後，我才知道什麼叫真正的搭檔。」
朋友：「你總是會在我卡住的地方剛好補上、我沒注意的細節你都看得一清二楚……就像是我腦海裡多了一顆外掛的 CPU。」
我沒說話，只是靜靜聽著。
朋友：「說真的，從以前到現在，我從沒這麼期待過一場比賽。」
主角：「今天就全力輸出吧。」
朋友：「說好了喔，要一起打到最後一題。」
我點了點頭。
主角：「嗯，說好了。」
天色漸亮。
資電館的燈光一盞盞亮起，像是程式即將執行的預告。
今天，我們是彼此的主程式，沒有人落單。
資電館教室裡，氣氛比往常更凝重。
我們並肩坐在靠窗的位置，陽光斜斜灑入，照在鍵盤與螢幕之間，映出指尖的輪廓。
你們身上背負的，是團體賽最後一戰。
朋友：「Ready？」
我沒有回頭，只低聲回了一句：
主角：「開始吧。」
倒數計時器歸零，指針切入比賽的第一秒，我們早已進入狀態。
我負責題目閱讀與整體策略，他則快速架起環境、配置測資、自動化模版同步。他敲鍵盤的速度比平常更快，像是在熱身，也像是在掩飾緊張。
我把第一題遞過去時，他接得乾脆。
主角：「這題給你。典型的區間 DP，你熟。」
朋友：「Roger that。」
幾分鐘後，他開口：
朋友：「你那邊圖論好解嗎？」
主角：「二分圖最小覆蓋。我先上個 Hopcroft-Karp。」
朋友：「那你等下留個口，我幫你寫 matching 的部分。」
我們像是共享一個思緒。每一句話不超過五個字，卻足以構成完整的語意。每一段交換，都是節奏的協調點。
他犯了一次小錯，把陣列 index 寫反了，提交被 RE。我沒說話，只是看了他一眼。
朋友：「我知道我錯了啦——拜託別用那個眼神看我，跟 code review 一樣嚴格。」
我默默把筆記推過去。
主角：「你 index 每次都會多減一。」
朋友：「嘖，知道了啦，我會改。真是的，冷靜得跟評測機一樣。」
他雖嘴上抱怨，手上卻已經在改 code。那份熟練不是假裝出來的，是這幾天一題一題打出來的節奏。
比賽進入最後一小時。
我們已經解掉三題，剩下最後一題——繁瑣的模擬混貪心，code 長、邊角多、需要協作的部分最多。
他主寫資料結構，我負責狀態機邏輯與 corner case 校驗。
朋友：「你那邊有個 bug，我幫你畫了個 flowchart放桌面上了。」
我抬頭，看到他用手寫筆畫的邏輯圖，不是漂亮的製圖，卻簡單清楚。
我沒說話，只是淡淡應了一聲。
主角：「……幫大忙了。」
朋友：「你講這句我會錄音存證的好嗎！」
他笑了一下，然後又回頭繼續敲字。明明是嘴砲，但這些話說出口時，我卻覺得胸口有一點點悶悶的酸。
他不是最聰明的，但永遠是最全力的那一個。
我在螢幕上敲下最後一個字，提交成功。
畫面跳出綠框：Accepted
他像是憋了很久似地猛地靠在椅背上，仰頭大喊：
朋友：「YES——！」
我轉頭看他，他咧嘴笑著，眼角微微泛紅。
主角：「做得不錯。」
朋友：「你才是。沒有你我根本不可能一路扛下來。」
主角：「你錯了。」
我淡淡地說：
主角：「是我們一起做到的。」
那一瞬間，他怔住了，像是什麼話卡在喉嚨說不出口。
但他沒說什麼，只是伸出手，握了握我的拳頭。
朋友：「……你真的變了。」
我看著他的眼睛，沒迴避。
主角：「因為有你，我才能變。」
比賽結束後，資電館的教室一如往常地喧囂。
有人歡呼，有人沉默，有人伏在桌上發呆——那是全力以赴後才能擁有的放鬆。
我們將電腦關機，並肩走出教室。
陽光從資電館的玻璃天窗斜斜灑下，像是特地為這一天，鋪上一層淡金色的濾鏡。
他揹著包，一邊走一邊咀嚼剛打開的能量棒。
朋友：「欸，我們這場表現算超穩吧？你說我們是不是有機會前三？」
我斜了他一眼，語氣平淡。
主角：「說不定第二。」
朋友：「蛤，真的假的？你不是那種會亂誇人的人欸。」
主角：「我沒誇你，是我們一起贏的。」
他愣了一下，隨即大笑。
朋友：「哇靠，你這句話比比賽得獎還讓我感動欸。」
我們走到中庭，找了棵樹下坐下。風輕輕吹著，陽光透過樹葉的縫隙落在地上，一片斑駁。
他雙手抱膝，望著遠方的夕陽，語氣忽然變得低了一些。
朋友：「你知道嗎……我以前一直以為，這種活動就是來交功課的。」
我沒有接話，只是轉頭看他。
朋友：「第一天來的時候，我還想說，大家都那麼強，肯定沒人會理我。」
朋友：「我也試過組隊，但老是拖別人後腿。後來乾脆一個人寫，寫得爛了也不欠誰。」
他笑了笑，有點自嘲。
朋友：「然後我就遇到你了。」
我看著他，沒有插話。
朋友：「你一開始真的很難親近。像個沉默的演算法機器，連表情都不會變。」
我低聲回道：
主角：「那你為什麼還要一直找我講話？」
他歪著頭，嘴角勾起一個笑。
朋友：「可能……直覺吧。就覺得你這種人，會是我能信任的對象。」
他看向我，語氣不像平常那麼輕浮。
朋友：「後來我們真的組隊了。我才發現——不是因為我搭上你變得厲害，而是你讓我變得想要更強。」
他頓了一下，像是下定了什麼決心。
朋友：「……我想變得足以跟你並肩的人。」
我一時間沒說話，只覺得胸口微微一震。
我們安靜了一會兒，夕陽把影子拉長，像把過去幾天的回憶全都投映在我們腳邊。
他忽然偏過頭看我，語氣裝作隨便。
朋友：「欸，我問你一個問題。」
主角：「說。」
朋友：「你覺得……我們這樣，算朋友嗎？」
我看著他，沒馬上回答。
他乾笑一聲。
朋友：「……抱歉，問得太蠢了對吧？」
我搖了搖頭，語氣很輕。
主角：「不是。」
主角：「是因為——我覺得，我們早就不是『只是朋友』那種模糊的距離了。」
我望著他，眼神平靜卻堅定。
主角：「我們是隊友。是可以把背後交給對方的那種人。」
朋友怔了一下，然後緩緩地笑了。
朋友：「……你說這種話真的太犯規了啦。」
他揉了揉鼻子，像是怕自己眼眶紅了會被我發現。
朋友：「那我也說一句好了。」
他伸出拳頭，輕輕撞了一下我的肩膀。
朋友：「如果哪天你需要人再跟你並肩打一次比賽，不管在哪裡、什麼場子……你只要開口，我都在。」
我沒有說話，只是伸出拳頭，與他輕輕相碰。
那一聲「喀」響，清脆又沉穩。
就像是把未來的某段路，安靜地約定下來。
我們的隊伍最終拿下了第三名。
不是頂尖，但足以讓人記得。我們上台領獎時，他笑得像孩子一樣，還偷偷比了個「V」。
我淡淡看他一眼。
主角：「這麼開心？」
朋友：「廢話，我這輩子還沒在這麼強的隊伍裡得過名次欸。」
主角：「這就滿足了？」
朋友：「才不是，我是想著——下次，我們可以衝更高。」
他說這話時語氣很輕，像是講一個不遠的計畫，而不是道別。
散場時，人潮湧向門口。
我拖著行李箱，跟著他一起走出教室。走廊上還留著今天比賽留下的紙杯、便條、和擦過無數次的地板痕跡。
校園裡的光線漸漸被橘紅色的夕陽取代。
我們默默地走在石板路上，肩並著肩。誰也沒說話，卻沒有任何壓力。
直到快走到校門口，他忽然停下腳步。
我也停住，轉頭看他。
他撓撓頭，像是在找什麼話當作告別。
朋友：「欸……」

主角：「不一定，也許是下一場比賽，也許是某個考場。」

主角：「你只要一開口，我就知道是你。」

朋友：「那你也記住了，我以後如果變強，第一件事就是來找你挑戰。」

朋友：「不准太努力喔，這樣我壓力會很大。」
主角：「那就追上來。」

那不是告別。
是約定。
幾年後。
你坐在比賽場館的選手區，一排排電腦螢幕閃爍著冷白光，鍵盤聲此起彼落。空氣中瀰漫著熱氣、咖啡香，以及隱約緊張的節奏感。
身邊是來自各校的頂尖隊伍，有人戴著耳機熱身，有人沉著地整理手邊的模板筆記。
你的眼神如往常般冷靜，手指在鍵盤上敲出初步的環境程式，腦中快速分析題型與策略分工。
一旁的隊友正將初步解法畫在草稿紙上，嘴裡還不忘喃喃自語。
朋友：「……喂，我說這題不是跟我們高二暑假營隊時做的那題超像的嗎？」
你抬起眼看他。他仍然是那副熟悉的模樣——髮型亂得沒救、眼鏡鏡片反著光，語速偏快、語氣熱血。但他的邏輯比從前更清晰，動作也比從前更成熟。
主角：「當年那題你不是卡了三十分鐘 TLE 三次？」
朋友：「欸欸欸，現在我是會 bitset 優化的男人了好嗎，請給我一點尊重！」
他咧嘴笑著，熟練地將範例輸入測資輸出模板全數貼好，回頭遞來一杯水。
朋友：「喝一下，三小時硬仗。」
你接過水，沒有多話。
主角：「你今天，別再多交 debug log 給我了。」
朋友：「你放心，我現在不只 code 不會爆，我連錯誤訊息都優雅得像詩一樣。」
你一邊看著題面，一邊淡淡回道。
主角：「希望你的詩不是 runtime error 寫的。」
朋友：「欸欸欸，你這樣嘲諷我很難專心欸。」
你嘴角輕勾。這些拌嘴，從未變過。
比賽開始。
你們像以往無數次練習過的那樣分工、協作、交替 debug、拆解重構。沒有人聲高呼，沒有人拍桌焦躁，只有一種平穩而有力的節奏——像兩條並行的演算法，一起穩步推進，彼此依賴。
當螢幕跳出最後一題的綠框，Accepted，那瞬間你下意識抬頭。
他已經搶先一步站起來，朝天比了個拳。
朋友：「YES！AC Hunter 再一勝！」

主角：「你還記得這個隊名？」
朋友：「廢話，那不是我們第一場正式比賽時自己取的嗎？」
你點點頭。
主角：「從來沒換過。」
朋友：「從來沒散過。」
他回得毫不猶豫，眼神帶著笑，卻比任何時候都認真。
你站起來，與他並肩走出場館。
場外陽光明亮，風吹過旗幟與選手的背影。你們的步伐像是經過無數場戰役洗鍊後的默契——安靜，卻堅定。
他忽然偏過頭，語氣像是開玩笑，卻又藏著些什麼。
朋友：「欸，你說我們這樣算什麼？」
你側頭看他。
主角：「怎樣？」
朋友：「不是情侶，不是兄弟，也不是戀人……你說，這段關係到底該怎麼叫？」
你頓了一下，沒有立刻回答。
但幾秒後，你轉過身，舉起拳頭。
主角：「叫這個就夠了。」
朋友一愣，隨即笑了出來，拳頭重重與你相碰。
那聲響落下時，你知道——這段友情沒有標籤，沒有劇本，也不需要定義。
它只是一路走來，從來沒有中斷。
只要彼此仍在，就永遠是搭檔。
你們並肩走進夕陽下，背影拉得長長的。
這一切——從不需要誓言。
這本來就是，你們約定好的事。

午後的鐘聲剛落，你便走進教室，冷氣迎面而來，讓人從夏日午後的燥熱中緩緩回神。教室裡已有不少學生陸續入座，氣氛安靜而專注。你一眼瞥見靠窗那排的兩個熟悉身影——妹妹和朋友。
妹妹坐得筆直，雙手抱著筆記本，比早上看來更加緊繃；朋友則輕鬆自在，正和旁邊的人有一句沒一句地閒聊。你走近時，他眼尖地注意到你，立刻招手。
朋友：「嘿！我這邊幫你留了位子，快坐下啦！」
你點點頭，默默在他與妹妹之間坐下。妹妹瞄你一眼，小小地哼了一聲，嘴角卻不自覺揚起一點弧度。
妹妹：「我才沒等你來……只是剛好而已。」
你沒多說，只是輕輕翻開筆記本，準備開始這堂圖論課程。
講師走上講台，簡單寒暄幾句後，開始投影簡報。
講師：「首先我們來談談圖的基本概念。」
螢幕上浮現一張節點與邊清楚標示的圖，「無向圖」、「有向圖」、「邊權」等詞語接連出現。
你邊聽邊抄筆記，餘光瞄到朋友寫得飛快，還不時畫小圖。反倒是妹妹緊盯簡報，眉頭微微糾著，像努力要把每個細節都記下。
講師：「接下來是存圖方法，常見的有……鄰接矩陣、鄰接串列……，各自的優缺點是……」
講師講解得簡明扼要，但一開始內容還是讓不少人一頭霧水。朋友皺眉，小聲問你。
朋友：「欸欸，那個鄰接串列到底怎麼寫啊？我感覺會一直寫錯 index……」
主角：「vector 配 pair，建圖時照輸入 push_back 就好。」
朋友：「喔喔喔，我懂了！你講得比講師還直白欸。」
你沒多說，只是淡淡繼續抄重點。
講師接著講 BFS 和 DFS，螢幕上顯示一張迷宮圖，紅線分別代表兩種走訪順序。
講師：「這張圖從節點 A 開始，用 BFS 的話，順序會是……而 DFS 則走這條路……」
妹妹筆尖動得飛快，忽然停下來，低聲嘀咕。
妹妹：「啊……我剛才把 DFS 的 stack 搞反了……」
你側頭看她一眼。
主角：「先進去的點會最後出來，記得反過來。」
妹妹：「我知道啦……只是……我想的是從右邊開始嘛。」
嘴上還是倔強，但她眼神明顯放鬆不少，筆也重新動起來。
講師繼續示範 BFS 的實作，強調 queue 如何 push、pop，還有 visited 陣列的重要性。
你邊聽邊在腦裡跑過幾道以前練過的題，確認自己還算熟悉。
講台上的語調平穩，投影機發出微弱嗡鳴。你翻到筆記下一頁，準備迎接後半堂課。
課程進入中段，講師翻到投影片，畫面上浮現一張加了權重的圖。
講師：「接下來我們來講最短路。」
教室裡響起壓低的討論聲，有人開始在紙上畫圖推演，有人則對 Dijkstra 感到陌生。
朋友側過來，低聲問道。
朋友：「欸欸，你覺得 Dijkstra 比好用，還是 Bellman-Ford 比好？」
主角：「看情況。Dijkstra 只能處理非負邊權，快一點；Bellman-Ford 可處理負權圖，但複雜度高很多。」
朋友：「……聽起來就是前者比較香啊。」
主角：「沒辦法通吃所有題型。」
他露出「你又講道理我又輸了」的表情，悄悄收回筆記本，繼續聽課。
講師在投影片上秀出了一個環狀圖，開始講 Prim 和 Kruskal 兩種最小生成樹的差異與實作邏輯。
講師：「這裡要注意，Kruskal 通常需要搭配 Disjoint Set Union，才能避免產生環。」
你一邊聽，一邊在紙上畫一個 union-find 流程圖。
妹妹在你旁邊還卡在邊排序細節，手指輕敲下巴，眉頭皺得更緊。她小聲嘀咕。
妹妹：「是先照邊權排……然後怎麼知道要不要選那條？」
你側頭看她一眼。
主角：「判是否造成環。」
妹妹：「那要怎麼判……啊，是不是就是早上講的那個……DSU？」
她眼睛一亮，語氣也變得急切。
你點點頭。
主角：「是。」
她嘴角揚起，像是抓到重點的孩子般，自顧自記了幾行筆記。
你視線回到講台，畫面已切到最後一章。
講師：「最後，我們來簡單介紹拓撲排序。這在 DAG 特別常見，比如處理先後順序問題時很有用……」
投影上出現一張課程先修圖，節點代表科目，邊則代表「需要先修」的依賴關係。你看著圖，不禁聯想到剛才的選擇——基礎或進階——彷彿也是某種拓撲排序下的抉擇。
講師用簡單例子示範 queue 的使用，畫出課程拓撲排序流程，說明「入度為零」節點要怎麼依序處理。
講台下學生紛紛開始在紙上畫圖、排順序。你早已記得這流程，但還是跟著筆記一次。
妹妹看起來有些吃力，她盯著紙上的箭頭圖，嘴唇微動，像在默背。
朋友早就放棄，草稿紙畫滿亂七八糟的圈圈箭頭，最後甚至畫起簡筆漫畫。
朋友：「這課也太燒腦了吧……我要去進階那間反而會直接炸掉欸。」
你沒接話，只是抄完最後一個例子。
課程結束前，講師提醒大家有機會回去練練經典圖論入門題。你收拾筆記本，看了眼身旁兩人。
妹妹臉上有些疲憊，但眼神仍盯著投影片，不肯錯過最後一個字；朋友則一臉「我想下課」的表情，仰天長歎。
你靜靜拉上拉鍊，準備離開。

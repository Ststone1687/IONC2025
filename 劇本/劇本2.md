# 序章

窗外的陽光懶洋洋地穿透窗簾的縫隙，灑在桌面上。

你側過身，讓陽光恰好掃過你的髮梢，然後伸了個懶腰，背脊微微彎起又再度挺直。

涼意自窗外竄入，帶來一縷夏日清晨特有的草木清香。

你低頭看了眼桌上的背包與筆電包，指尖在冰涼的金屬拉鍊上輕輕敲了兩下，像是在確認每一樣物品都穩妥就位。

時鐘的指針滴答響動，告訴你：該出發去清大了。

你再次確認行李，確保所有物品都已妥善地準備好。

「差不多該走了吧。」

背後忽然傳來熟悉卻略帶不耐煩的聲音。

「哥，你好了沒？」

你回過頭，看見妹妹站在門邊，雙臂環抱胸前。她的眉眼依舊帶著倔強的冷漠，卻被偶爾閃過的不安出賣。

「差不多了，再確認一下就好。」

妹妹輕哼一聲，側過臉去，故意避開你的視線。

「每次都是這樣，總是拖拖拉拉⋯⋯」

你無奈地搖頭，提起背包走到她身邊。

「好了，走吧。」

妹妹迅速抬頭，瞥見你已經準備完畢後，臉上的神情明顯緩和許多，但依舊逞強地別開視線。

「早就該這樣了。」

兩人踏出家門。晨風帶著一絲涼意，拂過你後頸的汗毛。

街道還未完全喧囂，零星的行人拖著睡意，腳步悠然。

妹妹的鞋跟輕敲柏油，卻隱約帶著興奮。

這是你們兄妹倆第一次一起參加營隊。

你側頭看向妹妹。

「你是真的想參加IONC？」

她腳步一頓，微微皺眉，然後抬頭。

「廢話！當然啊，不然我幹嘛跟你一起出門？」

你望向前方的街角。

「只是⋯⋯這種程式營隊好像不太適合你？你不是一直對文學和繪畫比較有興趣嗎？」

妹妹的臉頰微紅，頭撇向一側。

「你管我啊！我想參加不行嗎？而且，我又不是為了你才來的⋯⋯」

她低頭加快腳步，聲音從背後傳來。

「沒什麼啦，快走啦！要是錯過車，就你要賠我一杯珍珠奶茶！」

你輕笑，跟上她的步伐。

──

終於抵達清大校門口時，陽光已經高掛在天空正中央，熾熱而明亮。校門柱上的雕刻在光影下顯得古樸而莊嚴。

報到處旁，人群熙熙攘攘，歡笑聲與招呼聲此起彼伏。

你和妹妹走到報到處前，工作人員微笑迎上。

「歡迎來到IONC！請在這裡簽到，然後領取識別證與資料袋。」

你接過筆，快速填寫資料。

妹妹在你身側，偷偷用眼角餘光瞄著你，像是在觀察你的反應。

「別擔心，不會有問題的。」

妹妹頓了頓，隨即扭過頭去。

「誰在擔心啦。」

完成報到後，你們拿著印有營隊標誌的資料袋，踏進充滿未知與期待的校園。

微風拂面，帶來青草與書本交織的氣息，你抬頭凝望遠方——這一刻，所有挑戰與收穫都在前方等著你。

# 營長時間

你跟著妹妹踏入教室，推開的瞬間，一股溫暖的微光湧入眼簾。

講台上的投影機正處於待機狀態，藍色的待機燈在微暗的講台下格外醒目。

窗外的樹影隨著微風搖曳，透過落地窗投下一格格剪影，與教室裡的熱烈討論聲交織成一幅動態的畫面。

你在門口稍作停留，注意到左側角落已經聚集了幾位同學，他們低聲交談，偶爾傳來輕笑。

另一旁，則有人專注地在編寫程式，指尖飛快跳躍，彷彿每一行程式碼都在訴說一段故事。

你的目光順勢落到妹妹身上。她站在你身側，稍微踮起腳跟，手臂緊緊環抱，像是在用身體築起一道保護牆。

她的髮絲被微風輕撫，偶爾落在額前，令她不自覺地伸手撥開。

你輕輕吸了口氣，感受到胸口悄然跳動的節奏。這是你們兄妹第一次一起踏進這樣熱鬧的場域，既新奇又帶著一絲緊張。

〈要不要先跟她說點什麼？〉

你微微靠近妹妹，能聽見她輕輕呼吸的聲音。

教室裡的交談聲此起彼伏，卻像有一層薄膜隔絕了你們的距離。

你想要開口，但話語在舌尖懸停。

或許，現在是拉近彼此距離的好時機。

但另一個念頭瞬間掠過──如果先去上廁所，把心神暫時抽離，又能讓自己回到講台前時更沉穩。

此刻，你該如何選擇？

[跟妹妹聊天] / [去上廁所]

## [跟妹妹聊天]

你靠近妹妹一點，微微側頭，語氣盡量放柔：

「…緊張嗎？」

她愣了愣，抬頭看你，眼底閃著未消的忐忑，卻還是倔強地低聲回應：

「…才沒有。只是……環境有點新鮮。」

你伸手，輕輕推了推她的肩膀，語調平靜：

「如果有什麼不習慣，隨時告訴我。」

妹妹抿了抿唇，眼神短暫柔和，又迅速轉開：

「不用特別照顧我，我自己會好的。」

你點點頭，目光溫柔而堅定：

「我知道。但別把所有事都憋在心裡。」

她咬了咬下唇，終於露出一抹頭微垂的笑意：

「…謝、謝謝你，哥哥。」

你露出淡淡笑容，伸手攬過她的肩膀：

「走吧，我們找個座位坐下。」

## [去上廁所]

你輕咳一聲，抬起手背了下嘴角，語氣平淡：

「……我去一下廁所。」

妹妹點頭，並未追問，你轉身離開，步入走廊。教室門在身後輕輕關閉，瞬間隔絕了裡面的喧囂。

走廊兩側的白色牆面泛著光澤，你握緊書包帶，心跳逐漸平穩。推開廁所的門，伴隨一聲細微的「咯吱」，空氣中彌漫著清潔劑的氣味。

你走到鏡前，看見自己有些緊繃的眉眼，深吸一口氣，輕聲對著鏡中的自己說：

「深呼吸，一切都會順利的。」

洗手台上的水龍頭發出清脆的水聲，你俯身讓涼水拍打掌心，帶來一陣清醒。

整理了一下髮絲與襯衫領口，你轉身離開。經過走廊時，你對著還在調整設備的助教點了點頭，對方投來鼓勵的微笑。

回到教室門口，你深吸一口氣，推門而入。妹妹看到你回來，眉眼微挑，露出疑惑的神情。

「你好了？」

你點頭微笑：

「嗯，回去坐吧。」

你們並肩走回座位，準備迎接接下來的營長致詞。

營長邁著穩健的步伐從教室門口走進來，陽光在他背後拉出一條長長的影子，似乎為他鋪展了一條專屬的光道。教室中的交談聲頓時收斂，所有人的目光都被他吸引；投影儀的待機燈在此刻黯然失色，他的出現宛如一場序幕的揭開。

他微微抬頭，在全場掃視一圈，眼神溫和卻堅定，嘴角輕輕上揚，露出親切而自信的微笑。那笑容猶如冬日裡的一縷暖陽，驅散了夏日晨風中潛藏的緊張，也讓人不自覺地挺直腰背。

周遭開始響起陣陣掌聲，有人甚至不自覺地站起身來，手中筆記本落地的輕響打破短暫的肅靜。營長微笑著舉起一隻手，示意大家安靜下來，聲音洪亮、充滿磁性，卻又不失親切。

「各位同學，歡迎大家來到IONC營隊！在這幾天內，希望各位都能展現自己的實力與熱情，勇敢挑戰自我，享受程式解題的樂趣！」

他頓了頓，眼神掃過講台下每一張年輕的面孔，語調略帶激情：「無論你是初次接觸演算法的菜鳥，還是已經在程式世界裡歷練多時的老手，這裡都是你們展現思考火花的舞台。希望大家彼此切磋、互相激盪，讓這段共同奮鬥的時光成為人生難忘的篇章。」

掌聲再次響起，高低起伏，彷彿一波又一波的浪潮，席捲整個教室。助教們也露出鼓勵的笑容，在一旁熱情地點頭。你能感受到胸口的悸動：這份熱烈，正是你一直渴望的挑戰。

你深吸一口氣，目光不自覺地落在營長臉上那抹溫暖的笑意。他的每一字每一句，都像是為你量身訂做的鼓勵。你緩緩抬頭，視線在講台與妹妹之間來回，看到她眼中閃現的期待與微微上揚的嘴角，內心更加堅定。

〈我一定要把握這次難得的機會，不再讓自己退縮。〉

你默默在心中立下決心，跟隨全場的掌聲，一同邁入這場屬於程式解題的冒險。

# 基本技巧課程

投影幕亮起，淺灰色的背景上漸次出現深藍色的流程圖與程式碼片段。講師身影被背後的光線拉長，他拿著簡報遙控器，語調溫和卻富有磁性，讓人不自覺地屏息凝神。

你坐在第四排，筆記本攤開，筆尖輕輕劃過紙面，跟著講師的節奏記下重點。妹妹坐在你旁邊，偶爾還會側頭用眼角餘光瞥向投影幕，指尖也在筆記本上敲出零星的筆記。

教室裡有同學舉手提問，也有人低聲交換筆記。助教在講台側邊解答提問，投影幕上的代碼範例隨即更新，從簡單的 O(n²) 暴力破解，到利用二分搜尋將複雜度壓至 O(n log n)，每一個轉折都讓人眼前一亮。

你感受到筆記本下方鍵盤的質感，心裡暗自思索：

〈這些技巧雖然是基礎，卻像是組成更複雜演算法的拼圖。只要把每塊拼圖拼好，以後就能拼出更多解題路徑。〉

講師停下腳步，環視全場，語氣帶著一分期待與叮嚀：

「記住，程式競賽考驗的不只是你的程式技巧，更考驗你的細心與耐心。」

教室頓時又響起一陣點頭與筆尖劃過紙面的聲音。有人輕輕嘆息，似乎在回味講師剛才提到的「細心檢查邊界條件」；也有人眉頭微皺，仿佛正在思考如何將二分搜尋套用到下一個範例。

你放下筆，抬頭凝視投影幕上一行行演算法步驟，腦海中浮現接下來練習題的輪廓。妹妹在你身側輕輕咳嗽，示意下一個筆記重點：

「……當資料集中存在重複元素時，邊界判斷要特別留意，否則容易陷入無限迴圈。」

你快速在筆記旁加上粗線，提醒自己回去要反覆演練。

〈這堂課果然非常實用，不只是靠直覺編程，更要靠推敲與驗證。〉

投影幕轉至示範題目，講師邀請同學上台演示，現場互動熱烈。你握緊手中的筆，暗自告訴自己：

「等下…我也要試著上去，用今天學到的技巧親手解出那道題目。」

# 晚餐時間

你端著餐盤，挑了個靠窗的長桌空位坐下。桌面微微泛著暖黃色的燈光，餐廳裡彌漫著飯菜香與輕柔的交談聲。

妹妹也自然地坐到你身旁，將餐盤輕輕放下，低頭挑選菜色。

不久後，一位穿著簡約襯衫的同學在你另一邊落座，微笑向你揮手。

「嗨，今天的課程怎麼樣？」

你抬頭看他，語氣平靜地回答：
「還不錯，內容很實用。」

他點點頭，將托盤靠近桌邊，將菜擺好，又順勢看了一眼妹妹：「妳也一起來吃飯嗎？」

妹妹微微抬頭，輕聲道：
「嗯，和他一起。」

你感受到妹妹指尖微微顫抖，但她馬上別過頭去，專注在碗裡的湯汁。

同學微笑道：「妳哥看起來很會整理筆記，我剛才借過他筆記，對演算法理解更清晰了。」

你低頭喝了口湯，淡淡地回應：
「多謝誇獎。」

同學眼神帶著幾分認真：「有什麼不懂的地方，可以一起討論。」

你輕點頭，心中暗自記住：〈這樣一起交流或許能更快解題〉。

你們一邊聊 Code 模板，一邊搭配餐廳的吵雜聲，卻讓人更有團隊的溫度。

──就在這時，一位氣質出眾的學姊走到你面前，微微鞠躬，聲音柔和而有禮：

「我可以坐在這裡嗎？」

你抬眸看她，平靜地點頭：
「當然可以。」

學姊輕輕坐下，將資料袋放在椅背上，露出感激的笑意：
「謝謝。剛才聽你們討論，那段二分搜尋的邊界條件挺有道理……可以再講講你們的流程嗎？」

你思考片刻，簡潔地梳理：
「先確定左邊界與右邊界，再根據中點比較值後移動指標，最後再驗證結果是否落在目標範圍內。」

學姊認真點頭，隨即露出欣賞的目光：
「聽你解說比課堂演示還清晰，真厲害。」

你微微一笑，輕聲回應：
「謝謝，我只是習慣先在紙上推演。」

學姊轉向同學：「你們還有哪裡想討論的嗎？」

同學笑著搖頭，靜靜聽學姊補充一些優化建議。

妹妹看見這一幕，雙頰微鼓，低聲嘀咕：
「真是莫名其妙……」

你沒有特別注意到妹妹的小情緒，繼續和新認識的朋友們交談著，心中卻湧上一絲暖意：這頓晚餐，或許會是你收穫友誼與羈絆的開始。

# 第一次上機考試

教室裡的燈光被投影儀的冷白光映得更為清晰，電腦螢幕前的紅綠指示燈微微閃爍。你坐到指定座位，整個人像是被吸附在螢幕前，空氣中只剩下鍵盤敲擊的節奏。

你深吸一口氣，手指懸在鍵盤上，像是在對自己下最後的動員。

〈冷靜下來，先把題目讀清楚〉

你低頭快速瀏覽題面，注意到輸入輸出範例，以及時間與記憶體限制。思路在腦海中飛速運轉，算法的雛形隨即浮現。

你開始敲下第一行程式碼，指尖感受到鍵帽清脆的回彈，心中不禁湧起一陣暢快感。

鍵盤聲──

「卡、卡、卡……」

──此起彼落，猶如一支交響樂。你時而停下，眉頭微皺，檢查邏輯；時而加快速度，將函式一行行補齊；又於最後一刻，跳轉、測試、修正。

〈還差一個邊界條件……〉

你在程式末尾補上判斷，按下編譯鍵。終於，四個測資全數通過，螢幕上顯示「Accepted」。

你輕輕鬆了口氣，目光在螢幕與週遭同學間掃動，心中微微一笑：第一次上機考試，順利過關。

# 晚上

宿舍門在你身後輕輕關上，一股混合著洗澡水氣與書本味的熟悉氣息湧入。你抬頭，看見剛才晚餐時認識的那位同性朋友正靠在床邊椅背上，手裡翻閱著筆電裡的題目解析。

他抬頭見你入房，露出親切的笑容，揮手招呼：

「哈哈，真巧！原來我們是室友啊，這幾天請多指教囉。」

你將包放在書桌下，點頭回應：

「嗯，請多多指教。」

他拍了拍床頭，示意你坐下，然後合上筆電，共享螢幕給你看他剛剛優化的程式碼。

「你這邊考試怎麼樣？那道贪心題有沒有想到更好的做法？」

你走到他身邊，目光掃過螢幕上的註解，慢慢點頭：

「思路不錯，但時間複雜度還能再降一級，用堆疊來維護狀態應該更快。」

他眼睛一亮，將程式碼改寫成新的版本，你們邊討論邊測試，笑聲與鍵盤聲交織。

直到走廊的燈光熄滅前，你們才依依不捨地各自回床位。
你簡單整理桌面，脫下鞋子，攤開床單，感覺一天的疲憊逐漸蔓延。閉上眼前，你在心裡默念：

〈明天還有更多挑戰，得好好休息。〉

妹妹已在對面床上翻了幾頁書，見你躺下，側過身小聲道：

「累了吧？要不要先睡一會兒？」

```
for i in 2..n:

  for p in primes:

```

```
inv[1] = 1
for i in 2..n:
  inv[i] = (m - m/i) * inv[m % i] % m
```

這樣就不必重複用費馬小定理多次。」

就在你準備繼續細談時，妹妹微笑舉手插嘴：
「其實，我覺得我們可以再加一個步驟──排序每段子問題的輸入大小，讓最重的先執行，這樣就能更平均地分配計算量。」

你和眾人一愣，隨即驚訝地點頭：
「好主意！這樣能避免某些子問題卡住太久。」

學姊對妹妹豎起大拇指：
「這思路很不錯，感覺能進一步降低最壞情況的執行時間。」

朋友笑著將筆記本滑到妹妹面前：
「你先畫個流程圖，我們一起調整之後就實作。」

妹妹自信地在紙上快速畫出幾個框架，眼神專注而堅定。你看著她，心中湧起一股驕傲：這幾天她的成長超乎想像。

她偶爾轉頭對你眨眼，輕聲說：
「哥，這樣一起合作感覺更有效率吧？」

你回以一抹溫柔的笑意：
「嗯，有你在，團隊更強大了。」

此刻，妹妹自然地參與討論，不再刻意躲避視線，而是自信地與大家交換意見——她在這最後一天，以全新的姿態與你並肩作戰。

# 下午課程：常數優化

投影幕上閃現密密麻麻的程式碼，營長站在白板前，用紅筆圈出每一處可優化的細節：「在迴圈中盡量減少條件判斷、使用位運算取代除法、預先配置好記憶體，這些都能顯著降低常數因子。」他示範將一段朴素的 `for` 迴圈改寫為手動展開（loop unrolling），並以 `scanf` 換成自製快速輸入函式，讓同學們見識到毫秒級的差距。

你在筆記本邊緣寫下重點註解，手邊的筆記愈發工整，指尖仿佛有了自己的節奏。當營長邀請同學上台演示時，你抬手申請，平靜走到講台前，將你昨天也用過的快速 IO 模板和 `-O3` 編譯開關一併展示，並現場測試：

「這段程式在 10^7 筆輸入下，從原本 1200ms 降到 250ms。」你報出數據，旁邊的投影數字瞬間從紅轉綠。

教室裡響起一陣驚嘆，朋友低聲驚呼：「太誇張了！」學姊也笑著點頭：「這技巧真實用。」營長在台下露出滿意的笑容，連聲稱讚：

「這位同學的優化手法非常到位，細節考慮得很周全，給你鼓掌！」

你微微鞠躬後退，輕輕在筆記本上劃下幾條加粗線，然後回到座位。

這時，你看向妹妹，她坐在你身旁，嘴角輕輕上揚，卻努力控制著表情，只讓眼底的羨慕與驕傲閃爍一瞬。她低聲嘟囔：

「……真、真是莫名其妙，明明只是一點小優化……」

你回以一抹溫柔的笑意，輕聲問道：

「有什麼想法想一起討論嗎？」

妹妹抿了抿唇，抬頭與你四目交會，語氣不自覺柔和了幾分：

「…我也想試試把迴圈展開，再用指標跳過邊界檢查……」

你點頭，伸手在她筆記的註解邊圈畫：

「很好，我們一起試試看。然後再比較效能差異。」

學姊與朋友在旁聽到你們小聲的討論，也紛紛湊過來，伸出筆記本蓋章：

「這點子不錯，可以再加個記憶體對齊（alignment）提升快取命中率。」

你們四人低聲交流，思路如潮水般迸發。此刻，教室裡不只是營長的講解，更因為你們的互動，讓「常數優化」成為一場頭腦風暴，也讓妹妹在你的身旁，露出真正的笑容。

# 第四天吃晚餐

你端著餐盤走向長桌，今晚的菜色比往常更多樣，有烤鮭魚、焗烤杏鮑菇和螺肉清湯。妹妹一路跟在你身旁，臉上帶著一抹難掩的期待。

「終於輪到我請客了，今晚吃什麼想吃？」你笑著問。

「隨便，只要有你都行……」妹妹立刻別過頭，語氣卻藏不住一絲調皮。

你們坐下後，朋友笑嘻嘻地開口：「聽說今天你把那段常數優化的程式又改得更小了，連我都看不懂了，快教教我們！」

你淡然地撥動碗裡的青菜：「其實就把迴圈再細分，減少邊界檢查就行了。」

學姊湊過來，揶揄道：「他又要開始講他的‘記憶體對齊魔法’了，小心別聽太多睡著。」

眾人哄堂大笑，妹妹卻扭頭悶聲反駁：「你才睡著呢，哪有那麼悶！」

你笑著看向妹妹：「沒關係，下次我把重點寫在餐巾上給你看。」

妹妹臉頰微紅，語氣卻硬撐：「才不要呢，我自己有筆記！」

朋友舉杯示意：「為了最強優化之王乾一杯！」

你們一同舉起飲料，發出清脆的碰杯聲。妹妹也鼓起勇氣舉杯，嘴角含笑地對你說：「……我也算喝一口好了。」

學姊眨眼：「看來妳也認同他的厲害了？」

妹妹立刻翻白眼：「才、才不是因為那個！」卻忍不住對你露出勝利的眼神。

你輕輕摸了摸她的頭：「今晚好好吃飯，明天再繼續挑戰最後的終極題。」

妹妹翻了個身，靠在椅背上，目光柔和地看著你和大家，低聲補充：「……謝謝你帶我來這裡。」

此刻，燈光灑在每張專注而愉快的臉龐上，晚餐的笑語與玩笑交織，讓這最後一晚充滿溫暖與歡樂。

# 第四天上機練習

實驗室內只剩螢幕發出的冷光與鍵盤清脆的敲擊聲，每一個秒針都顯得格外清晰。題目聚焦在常數優化的細節：如何在緊迫的時間限制下，將原本 800ms 的演算法壓縮到 500ms 以下。你和室友迅速分工，他先在記憶體對齊與預取技術上動手，而你則負責手動展開迴圈、移除不必要的分支檢查。

你在便條紙上畫出程式執行流程，並低聲向室友確認：
「我們先把核心迴圈展開四倍，再用指標跳過邊界檢查，可以避免費時的 if 判斷。」
室友握拳回應：
「我來處理 prefetch 與對齊，確保 L1 快取命中率最大化。」

隨著時間一分一秒流逝，你們互相掀開程式碼、互相整合最後一段優化。當指標步進與記憶體預取協同運作時，螢幕上顯示的運行時間從 530ms 下降到 480ms。你深吸一口氣，按下最終的 `Submit`。

「Accepted」的綠色字樣在最後一秒閃現，全場爆出掌聲。

營長走上前，語氣洪亮：
「這組同學在最後一刻完成所有題目，效率與品質兼具，給你們最熱烈的掌聲！」

你與室友相視而笑，擊掌慶祝，心中充滿成就與釋放感。

# 第四天回宿舍

夜深的走廊格外安靜，只有燈光在牆面投下溫暖光暈。你推開宿舍門，室友已將床邊燈留一盞微弱，等待你進門。

你放下背包，卸下整日的疲憊，轉身聽室友感嘆：
「明天就是最後一天了，感覺時間過得真快。」
你走到床邊，坐下回應：
「對啊，真的很充實呢。」

室友撥了撥桌上的筆記本，露出寬慰的笑容：
「這幾天學到的東西，比我預想的還要多。明天的成果發表，一定會很精彩。」
你點點頭，撫摸了一下手中的筆記本封面：
「嗯，我也很期待。先休息吧——還要養精蓄銳，迎接最後的挑戰。」

你打開被子，躺下後看向室友：
「晚安，明早見。」
室友應聲：
「晚安。」

宿舍內回歸寂靜，只剩彼此的呼吸聲。此刻，你在滿滿的回憶與期待中，緩緩進入夢鄉。
